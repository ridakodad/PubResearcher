# Police Poppins

Poppins (The Poppins Project Authors, https://github.com/itfoundry/Poppins), sous licence SIL Open Font License 1.1 : voir `OFL.txt`.

Quatre graisses (400, 500, 600, 700), sous-ensemble « latin » seulement (le français, avec ses accents, ses œ et ses guillemets), au format WOFF2. Extraites du paquet npm `@fontsource/poppins` 5.3.0. Elles sont servies par l'application elle-même : aucune police n'est téléchargée depuis un service tiers, l'outil continue de fonctionner hors connexion.

Les signes absents du sous-ensemble (≥, ≈, →…) retombent sur la police du système.
